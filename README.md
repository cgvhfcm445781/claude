# claude
## ユニバース(前提)の条件
#### 売買代金
◾️直近20日の平均で1日5,000万円以上\
売買が少ない銘柄は、思った値段で売り買いしにくいため
#### 株価
◾️1,000円以上、4,000円以下\
40万円で100株を買える範囲。検証では、この範囲のほうが順張りの成績も良かった
#### データの異常
◾️過去1年に、1日で±50%を超える動きがない\
株価データが壊れている銘柄を外すため

## 参照元
* 信用残はJPXの無料データから
* 予想PERはJ-Quants Lightから
## データ管理
* ポートフォリオはportfolio.csvで
* 所持資金設定はalert_config.jsonで
* 手放した銘柄はportfolio.csv から消して trade_history.csv に移される。
## このルールで運用するときに覚悟しておくこと
* 入れ替えのたびに、10銘柄中3〜4銘柄は損失で売ることになります。 これは想定どおりの動きです。
* 途中で-20%以上下げる銘柄も出ます。 そこで慌てて売らずに、次の入れ替えまで持つのがルールです。
* 損失を抑えたいときは、銘柄数を増やす（1株単位で各10銘柄など）のが一番効果的です。
