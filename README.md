# 週次シグナル
## 売買ルール
1. 急落リバウンド\
日経平均の4週騰落率-7%以下とVIXです。シグナルが出たときは、買う銘柄、+20%で利確の指値。届かなければ8週後の金曜大引け。
2. 割安株10銘柄\
PERが低い順。12か月線より上、信用残が重くない銘柄です。
3. 順張り+減益予想の銘柄を外す10銘柄\
過去12か月の上昇率が高い順。信用残が重くない銘柄です。
+会社が出している今期の営業利益予想が、前期の実績を下回る銘柄を外します。
4. 入れ替えのタイミング\
週ごとの入れ替えでリストから外れたら売り。


## ユニバース(前提)の条件
1. 売買代金\
直近20日の平均で1日5,000万円以上\
売買が少ない銘柄は、思った値段で売り買いしにくいため
2. 株価\
1,000円以上、4,000円以下\
40万円で100株を買える範囲。検証では、この範囲のほうが順張りの成績も良かった
3. データの異常\
過去1年に、1日で±50%を超える動きがない\
株価データが壊れている銘柄を外すため

## データ管理
* ポートフォリオはportfolio.csvで
* 所持資金設定はalert_config.jsonで
* 手放した銘柄はportfolio.csv から消して trade_history.csv に移される。

## このルールで運用するときに覚悟しておくこと
* 入れ替えのたびに、10銘柄中3〜4銘柄は損失で売ることになります。 これは想定どおりの動きです。
* 途中で-20%以上下げる銘柄も出ます。 そこで慌てて売らずに、次の入れ替えまで持つのがルールです。
* 損失を抑えたいときは、銘柄数を増やす（1株単位で各10銘柄など）のが一番効果的です。
